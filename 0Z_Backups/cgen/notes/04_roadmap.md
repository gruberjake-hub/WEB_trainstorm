# Roadmap

## Phase 1 – Rapid eLearning (Current)
Goal: Ship polished, static courses quickly.

- Lock v1 course schema
- Expand component library:
  - ImageWithCaption
  - Video (static)
  - ScenarioPrompt (single decision)
  - KnowledgeCheck
- Script → audio + captions pipeline
- Human-in-the-loop course compiler
- Deliver real client courses

---

## Phase 2 – Intent-Aware Generation
Goal: Improve quality without changing outward product.

- Add intent metadata (non-functional)
- Introduce semantic video overlays
- Improve rule expressiveness
- Increase AI design autonomy

---

## Phase 3 – Adaptive Trajectories
Goal: Hyper-adaptive learning.

- Probabilistic learner state model
- Bayesian belief updates
- Prompt context evolves per learner
- Fixed goals, adaptive paths

This phase is internal first.
