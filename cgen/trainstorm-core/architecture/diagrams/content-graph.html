Why it’s “reference,” not “embed”

Change once — propagate everywhere

Because the atom holds keys into these models instead of copies of them, one edit updates every atom that points there. This is the mechanism under the compounding.

Fix a glossary term once → every localization updates
Change a visual token once → every atom of that type re-renders
Revise an objective once → everything mapped to it re-aligns

…and it lands your principle exactly

Content = object + intent
Structure and meaning — the invariant truth. What exists, and what it’s for.
Expression = registries + render agents
The form — how the truth is shown, in language, layout, motion.
Facets = the wires
Keyed bindings from a thin atom to all three. The atom holds meaning; the models hold substance; facets connect them.

How this sits under the system map

This is the inside of the hub. Build the object model + identity first — that’s the spine, and you already have it. Intent and the registries accrete as the pedagogy and presentation agents need them. Binding-by-key is the invariant that keeps all three decoupled, so no model has to know another’s internals.
