# CGEN Treatment Index

## Scene Treatments

  Name                 Meaning
  -------------------- ------------------------------------------------------
  didactic-flow        Standard instructional delivery with balanced pacing
  emphasis-frame       Sparse scene emphasizing a key idea
  progressive-reveal   Information unfolds step-by-step
  contrast-frame       Two ideas in tension or comparison
  assessment-beat      Learner action required

## Unit Treatments

  Name                 Meaning
  -------------------- ----------------------------------
  primary-assertion    Core idea, visually dominant
  supporting-context   Supporting explanation or detail
  emphasis-beat        Highlighted key statement
  progressive-step     Step in a sequence
  contrast-pair        One side of a comparison
  interaction-prompt   Cue for learner interaction

## Rhetorical Treatments (examples)

  Name                   Meaning
  ---------------------- -----------------------------
  summary-highlight      High-level takeaway
  supporting-detail      Additional explanation
  emphasized-assertion   Strong persuasive statement
  plain-exposition       Neutral explanation
  knowledge-check        Assessment-oriented content
