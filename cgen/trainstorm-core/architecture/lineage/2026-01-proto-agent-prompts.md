# Lineage — the January 2026 proto-agent prompts (Brunswick pay-transparency engagement)

*Recorded 2026-08-31, at Jake's direction, during the Brunswick paytrans drive (the first
full-course drive). Tier: **lineage record** — history that explains the design, not canon that
constrains it. Where this file and `DECISIONS.md` disagree, DECISIONS wins.*

Before the manifold had agents, the Brunswick pay-transparency engagement ran on three hand-carried
prompts (BPS project folder, `_AiSeq_PayTrans_Brunswick/PROMPT_*.md`, Jan 2026). Jake's observation,
which this file records: **those prompts are the proto-forms of the agent roster**, and their
thinking should be woven into the graph where it isn't already. The audit below does that weaving —
by mapping, and by naming what is *not* yet absorbed, so it lands as carries rather than being
silently lost.

## The three prompts, and where each one's thinking now lives

### 1. `PROMPT_ingestion_project-context-md.md` — "Sense-Making Engine" → Headwater + the warrant chain

A corpus-ingestion prompt producing a **Context Digest** "before any instructional design begins."

| Its idea | Where it lives now | Status |
|---|---|---|
| Ingest holistically; establish shared understanding before building | Headwater `case_author` mode: scope-commit → committed-design artifact → mint | **absorbed** |
| Cite sources; facts vs interpretations; flag, never invent | The gate's invent-guard; Headwater's verbatim `source_text` discipline | **absorbed** |
| §2 Stated vs implied objectives | The objective derivation: objectives are DERIVED from outcomes, not supplied (decision-log 2026-08-21 later) | **absorbed** |
| §7 "training being used to compensate for structural or organizational issues" | `goal.reachability.not_trainable` — the same judgment, now a **required schema field** | **absorbed** — this is the strongest single line of lineage: the reachability filter existed in this prompt seven months before GAP-05 closed |
| §6 Signal vs noise (density-weighted reading) | Nowhere structural. Headwater authors judge it silently | **carry** — a candidate `sufficiency`-style annotation on ingest scope decisions |
| §9 Open questions for the project team | The intake-contract/socket pattern (ALSAP arc) has this shape for evidence; nothing asks it of a *corpus* | **carry** |

## The pipeline the three prompts formed

```
corpus → [sense-making → Context Digest] → [explore, hot] → [commit, cool → script] → build
             ↓ became                        ↓ became             ↓ became
         Headwater case_author           (no agent yet —      script primitives IR →
         + goal/reachability             parked Designer)     realize/cartographer/couturier
```

The manifold industrialized stages 1 and 3 and **has not yet given stage 2 a seat.** That is the
one structural absence this audit surfaces; it is already parked (Strategist / Designer,
STRUCTURE score 2026-08-30) and this file adds the provenance for what that seat should inherit.
