Brand rule insights captured

Brunswick is essentially a constrained marketing palette, not a learning UI system.
That means the practical solution is to derive a functional learning palette from the brand colors rather than using only the raw palette literally.

We discussed the idea that the real structure should be:

Marketing Brand
↓
Learning UI Palette
↓
Runtime Component Styling

Examples of semantic UI roles:

Key insight

Brunswick’s strict brand rules make traditional eLearning design harder because the guidelines are optimized for marketing/hero use, not high-density learning interfaces. The Trainstorm opportunity is to turn a static brand guide into a runtime-ready design system.

Adobe / Illustrator discussion

We also discussed how Illustrator and After Effects do not natively consume CSS or JSON as a theme system the way PowerPoint/Storyline use themes.

Recommended Adobe-side approach:

Illustrator: save brand swatches as .ase

Illustrator: optionally create an .ai template with swatches/styles

After Effects: create a BRAND_CONTROLS comp with color controls tied to expressions

Long-term: generate Adobe assets from brand.json
