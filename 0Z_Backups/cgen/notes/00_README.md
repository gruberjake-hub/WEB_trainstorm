# Notes – AI Learning Runtime (cgen)

This folder contains the **architectural intent, design philosophy, and AI steering context**
for the AI-driven native learning runtime.

These notes are **first-class infrastructure**, not commentary.

They exist to:
- Preserve design intent across time and collaborators
- Enable future AI instances to operate with full context
- Prevent regression into legacy eLearning patterns
- Make architectural decisions explicit and reviewable

If something explains *why* the system works the way it does,
it belongs here.

Execution lives elsewhere.
Intent lives here.
