Learning Systems Architecture · framework map

The Learning Content Manifold

One shared content substrate; many agents, each a “local chart” that reads and writes its own facet. They coordinate through the graph — never through each other. AST009 is the first proven agent on it.

The whole, in three planes

Content plane
The graph / manifold — atoms, typed relationships, layered facets. The single source of truth. Passive.
Agent plane
The engines. Each owns one facet, reads others, wakes on a graph state. Code, LLM, or human behind the contract.
Coordination plane
Mostly the graph itself as a blackboard — agents react to state. A thin layer adds ordering and human gates.

The map — agents as charts over one graph

No lines run between agents — only to the hub. That absence is the design: agents coordinate through the graph, never each other.

Each atom carries facets: presentation pedagogy adaptivity localization assessment governance

The invariants that keep it from tangling

Single-writer per facet. One agent owns each facet — no write conflicts, and ownership maps straight to governance.
Read anyone’s facet; write only your own. Agents share by reading, not by reaching in.
The graph is the only contract. Atom ID is the sole coupling — no agent calls another directly.
Choreography over orchestration. Agents react to graph state; add explicit sequencing only for gates.
Implementation varies behind the contract. Code, LLM, or human — swappable without touching the graph.
The graph is queryable. “Which regulatory atoms lack a validated JA locale?” is one traversal — the same walk the runtime uses to adapt.

How to hold this while you build pieces

Build one agent at a time against the graph — never against another agent. Localization (AST009) is real; the generator, pedagogy, presentation, and responsive agents can stay notional and still compose later, because they only ever meet on the shared substrate. The manifold is the thing you keep whole; the agents are how you ship it in parts.
